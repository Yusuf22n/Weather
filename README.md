# 🌤️ Weather App

Приложение для сравнения текущей погоды в разных городах с помощью графиков и карточек. Данные получаются из [OpenWeatherMap]

## 🚀 Возможности

- 🔍 Поиск городов с автоподсказкой
- 📊 График сравнения по метрикам: температура, давление, влажность, скорость ветра
- 🗑️ Удаление городов из списка
- 🌐 Поддержка нескольких языков (в текущей версии — русский)
- 🎨 Красивый и отзывчивый UI на React + TailwindCSS

## 🛠️ Технологии

- **React (TypeScript)** — современный фронтенд
- **Recharts** — для графиков
- **Axios** — запросы к API
- **TailwindCSS** — стилизация
- **Vite** — сборка и разработка
- **OpenWeatherMap API** — данные о погоде
- **Material-UI (MUI)** — компонент автоподсказки

## ⚙️ Установка

1. Клонируйте репозиторий:

git clone https://github.com/weather-compare-app.git
cd weather-compare-app

Установите зависимости:
npm install

Запустите приложение:
npm run dev
